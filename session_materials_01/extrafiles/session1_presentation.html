Object-Oriented Programming (OOP)

Let's look at generic, framework-relevant examples. These patterns are everywhere in AI SDKs.

1. Classes & Objects

Concept: A class is a blueprint; an object is an instance holding its own state.

class AIModel:
    def __init__(self, name, accuracy):
        self.name = name
        self.accuracy = accuracy

    def summary(self):
        return f"{self.name}: {self.accuracy}% accuracy"

model = AIModel("Model-A", 91.4)
print(model.summary())

🤔 Question for the Class

What will be printed to the console when this code runs?

Model-A: 91.4% accuracy

Framework Hint: This is the same pattern as instantiating any object in a library — a class is just a template.

2. Abstraction

Concept: Expose what something does, hide how. An Abstract Base Class (ABC) defines a contract.

from abc import ABC, abstractmethod

class BaseModel(ABC):
    @abstractmethod
    def predict(self, data):
        pass

class TextModel(BaseModel):
    def predict(self, data):
        return "positive" if "good" in data.lower() else "negative"

🧠 Check Your Understanding

What happens if we try to do this?

model = BaseModel()

Framework Hint: This exact pattern shows up in LangChain's BaseLLM/BaseChatModel — subclassing abstract classes is routine in GenAI frameworks.

3. Inheritance & Polymorphism

Inheritance: A subclass reuses and extends a parent's behavior.

Polymorphism: Different classes respond to the same method call in their own way.

class AdvancedModel(AIModel):
    def __init__(self, name, accuracy, version):
        super().__init__(name, accuracy)
        self.version = version

    def summary(self):
        base = super().summary()
        return f"{base} | version: {self.version}"

# Polymorphism in action
models = [AIModel("Baseline", 70.0), AdvancedModel("Advanced", 91.4, "v2")]
for m in models:
    print(m.summary())

🤔 Question for the Class

What output do we get from the loop?

Baseline: 70.0% accuracy
Advanced: 91.4% accuracy | version: v2

Framework Hint: This is why you can loop over a list of totally different agent tools/model wrappers and just call .run() on each. Polymorphism makes frameworks plug-and-play.

Git Basics

Before we build, we need to track. Why version control? Because team projects live and die by it.

git init                       # start tracking a project
git clone <url>                # copy an existing repo locally
git status                     # what changed?
git add .                      # stage changes
git commit -m "message"        # snapshot with a clear message
git pull                       # get latest before you start working
git push                       # send your commits

🚨 Golden Rules of Git

  • Commit early, commit often. Write messages a teammate can understand.
  • Always pull before you push to avoid conflicts.
  • CRITICAL FOR AI: Never commit API keys! Always use .gitignore for your .env file.

Exception Handling

In AI apps, APIs fail all the time. Rate limits, timeouts, bad JSON... Exceptions are your safety net.

1. try/except basics

try:
    result = 10 / 0
except ZeroDivisionError as e:
    print(f"Something went wrong: {e}")
finally:
    print("This always runs — cleanup goes here.")

2. Custom Exceptions

class ModelNotTrainedError(Exception):
    """Raised when prediction is attempted before training."""
    pass

class SimpleModel:
    def __init__(self):
        self.trained = False

    def predict(self, x):
        if not self.trained:
            raise ModelNotTrainedError("Call .train() before .predict()")
        return x * 2

m = SimpleModel()
try:
    m.predict(5)
except ModelNotTrainedError as e:
    print(f"Custom error caught: {e}")

🤔 Question for the Class

What gets printed here?

Custom error caught: Call .train() before .predict()

Framework Hint: Once you start calling LLM APIs, try/except wraps almost every call. Defensive programming is mandatory.

The Code

We load the API key from a .env file instead of hardcoding it.

from dotenv import load_dotenv
import os
from openai import OpenAI

load_dotenv()  # reads .env → OPENAI_API_KEY
client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

try:
    response = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": "What are the top 3 new developments in AI this month?"}]
    )
    print(response.choices[0].message.content)
except Exception as e:
    print(f"API call failed: {e}")

🔥 The Shape of GenAI Apps

Pay attention to the core pattern in this code. It repeats everywhere:

Input ➔ Model call (wrapped in try/except) ➔ Parsed response
