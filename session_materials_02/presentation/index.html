Multithreading vs Multiprocessing

Doing multiple things at once to speed up execution.

1. Multithreading

Best for I/O Bound tasks like network API requests or database lookups. In a Web Server, when Thread 1 is waiting for a slow database response (I/O wait), Python releases the GIL so Thread 2 can immediately serve the next incoming client without being blocked! 

import threading, time

def handle_client(name, wait_time):
    print(f"Serving {name} (waiting {wait_time}s)...")
    time.sleep(wait_time) # Simulating I/O
    print(f"Finished {name}!")

requests = [("Client 1", 3), ("Client 2", 1), ("Client 3", 1)]
threads = []

for name, wait in requests:
    t = threading.Thread(target=handle_client, args=(name, wait))
    threads.append(t)
    t.start()

for t in threads: t.join()

2. Multiprocessing

Best for CPU Bound tasks like heavy math, data crunching, or model training. A Process runs in its own memory space, bypassing the Global Interpreter Lock (GIL) to execute truly in parallel across multiple CPU cores. 

import multiprocessing

def heavy_math(num):
    return sum(i*i for i in range(num))

if __name__ == "__main__":
    processes = [multiprocessing.Process(target=heavy_math, args=(1000000,)) for _ in range(2)]
    for p in processes: p.start()
    for p in processes: p.join()
The Golden Rule: Use Multithreading when your program spends a lot of time waiting (e.g., downloading data from APIs, waiting for disk reads). Use Multiprocessing when your program needs raw computational power (e.g., crunching huge data arrays, machine learning) so it can leverage every core on your CPU.

HTTP Fundamentals

Under the hood of the internet and making requests via the requests library.

1. HTTP Methods (CRUD) & Status Codes

The internet relies on standard methods to interact with data (Create, Read, Update, Delete).

  • POST (Create): Sending new data (e.g., submitting a form, sending an LLM prompt).
  • GET (Read): Fetching existing data (e.g., loading a webpage, searching).
  • PATCH/PUT (Update): Modifying existing data.
  • DELETE (Delete): Removing data.

Common Status Codes:

  • 200 OK / 201 Created - Success!
  • 400 Bad Request - Your data is malformed.
  • 401 Unauthorized - Invalid API Key or login.
  • 404 Not Found - The endpoint or resource doesn't exist.
  • 429 Too Many Requests - Rate limit exceeded.
  • 500 Server Error - The API provider's server crashed.

2. The requests Library (GET & POST)

Making a GET request to fetch data, and a POST request to send data.

import requests

# 1. GET Request (Fetching Data)
response = requests.get("https://api.open-meteo.com/v1/forecast?latitude=52.52&longitude=13.41¤t_weather=true")
if response.status_code == 200:
    temp = response.json()["current_weather"]["temperature"]
    print(f"Berlin Temp: {temp}°C")

# 2. POST Request (Sending Data)
url = "https://jsonplaceholder.typicode.com/posts"
data_to_send = {"title": "Hello", "body": "World", "userId": 1}
post_response = requests.post(url, json=data_to_send)

print(f"POST Status: {post_response.status_code}") # 201 Created
print(f"Response: {post_response.json()}")

Robust APIs

API calls over the internet will fail. Defensive programming is required.

import requests
import time

url = "https://api.open-meteo.com/v1/forecast?latitude=52.52&longitude=13.41¤t_weather=true"
max_retries = 3

for attempt in range(max_retries):
    try:
        # Add timeout to prevent hanging forever
        response = requests.get(url, timeout=5)
        response.raise_for_status() # Raises Exception if status != 200
        
        print("Success!", response.json()["current_weather"]["temperature"])
        break # Exit loop on success
        
    except requests.exceptions.Timeout:
        print(f"Attempt {attempt+1} timed out. Retrying...")
        time.sleep(2)
    except requests.exceptions.RequestException as e:
        print(f"API Error: {e}")
        break # Non-recoverable error

Calling APIs (Advanced)

Applying HTTP concepts via SDKs and Hands-On practice.

1. Calling LLM (File Prompt)

Read the prompt from prompt.txt and write the LLM response to response.txt.

from dotenv import load_dotenv
import os
from openai import OpenAI

load_dotenv()
client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

with open("prompt.txt", "r") as f:
    prompt = f.read().strip()

try:
    response = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": prompt}]
    )
    reply = response.choices[0].message.content

    with open("response.txt", "w") as f:
        f.write(reply)

    print("Response saved to response.txt")
except Exception as e:
    print(f"API call failed: {e}")
