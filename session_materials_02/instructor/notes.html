📋 Session 1: Instructor Guide

1. Python Introduction

~3-5 min

Definition: Python is the foundational engine of modern AI models, serving as both the language they were built with and the toolkit they use to interact with the world.

🗣️ Mention: "Python isn't just about 'how to code' — it's about building strong software engineering habits to automate tasks and build robust AI pipelines."

🗣️ Mention: "When you see an AI writing and running Python code during a conversation, it is leveraging a capability called Code Execution."

2. Core Basics

~10 min

Goal: Establish how Python stores and manipulates basic information.

Variables & Types

Definition: Variables are named references to data stored in memory. Python determines the type automatically at runtime.

🎨 Visual Metaphor (Image Reference): Labeled Storage Boxes
Point to the image of the labeled boxes. Explain that when shifting a house, you put items in boxes labeled 'Books' or 'Clothes'. In Python, you just pack the data into a named box, and Python automatically knows if it's text (str), a number (int/float), or a boolean (True/False).

Operators

Definition: Symbols that perform mathematical, logical, and relational operations to evaluate state and compute results.

🎨 Visual Metaphor (Image Reference): Scales of Justice & Math Machines
Point to the image of the scales. Operators are the machinery that weigh and compare data (e.g., checking if accuracy > 90) to decide what the program should do next.

3. Control Structures

~15 min

Goal: Explain how programs make decisions and repeat actions.

If / Elif / Else

Definition: Conditional branching that dictates which block of code runs based on a True/False evaluation.

🎨 Visual Metaphor (Image Reference): Train Track Switch
Refer to the train track split image. The program is a train, and the if condition acts as the track switch — depending on the signal, the train diverts to route A (success) or route B (failure).

For Loops

Definition: Iterating over a collection of items sequentially, executing the same block of code for each item.

🎨 Visual Metaphor (Image Reference): Factory Conveyor Belt
Show the assembly line image. The loop body is a robotic arm, and the data list is a conveyor belt. The arm performs the exact same operation on every single box that comes down the line.

While Loops

Definition: Repeating a block of code continuously as long as a specific condition remains true.

🎨 Visual Metaphor (Image Reference): Running on a Treadmill
Refer to the treadmill image. You keep running (the loop keeps executing) UNTIL you hit a specific distance or get tired (the condition becomes False).

4. Data Structures

~15 min

Goal: Explain how Python groups multiple pieces of data into single, manageable structures.

Lists & Tuples

Definition: Ordered collections of items. Lists can be modified (mutable), while Tuples cannot be changed once created (immutable).

🎨 Visual Metaphor (Image Reference): Shopping Lists & Padlocks
A List is like a shopping list where you can cross things out and add new items. A Tuple is like GPS coordinates locked behind a padlock — it's fixed permanently.

Dictionaries

Definition: Collections of key-value pairs used for fast data lookup, directly mirroring JSON formats used in APIs.

🎨 Visual Metaphor (Image Reference): Filing Cabinet / Phonebook
You don't read a phonebook start-to-finish; you jump straight to the person's name (the Key) to find their number (the Value). This is exactly how AI prompt messages are structured.

Sets

Definition: Unordered collections of unique elements, perfect for eliminating duplicates and finding commonalities.

🎨 Visual Metaphor (Image Reference): ID Badge Scanner
A Set is like a security bouncer. No matter how many times someone tries to enter, the scanner ensures each unique ID is only registered once.

5. Functions, Modules & Packages

~10 min

Goal: Explain how to package code into reusable blocks and leverage external libraries.

Definition: A Function is a block of reusable code. A Module/Package is a collection of functions written by others that you can import.

🎨 Visual Metaphor (Image Reference): Recipe Box & Supermarket
Functions: A recipe box where you write down a cooking process once, and use it forever.
Packages: Going to the supermarket. Why mill your own flour when you can just import someone else's perfectly baked bread (like importing OpenAI's library)?

6. OOP Concepts

~20 min

Goal: Introduce Object-Oriented Programming as the fundamental architecture behind all GenAI frameworks (LangChain, LlamaIndex, etc).

Classes & Objects

Definition: A Class is a template for creating objects. An Object is a specific instance containing state (data) and behavior (methods).

🎨 Visual Metaphor (Image Reference): Blueprints & Robots
The Class is the paper blueprint. The Object is the physical robot built from that blueprint.

Abstraction

Definition: Hiding complex implementation details and exposing only the necessary parts to the user.

🎨 Visual Metaphor (Image Reference): Car Steering Wheel
You don't need to know how the fuel injection works to drive a car; you just turn the steering wheel. Abstraction provides the steering wheel.

Inheritance & Polymorphism

Definition: Subclasses inheriting traits from a parent class, but reacting differently to the same commands (Polymorphism).

🎨 Visual Metaphor (Image Reference): The Animal Kingdom
A base "Animal" class has a "speak()" command. A Dog subclass barks, and a Cat subclass meows. Same command, different behavior.

Encapsulation

Definition: Restricting direct access to an object's internal data, forcing interaction through specific methods.

🎨 Visual Metaphor: Safe with a Combination Lock
You can't just grab the money inside the safe; you have to interact with the lock (the method) using the right code to get access.

7. Exception Handling

~10 min

Goal: Teach defensive programming to prevent applications from crashing.

Definition: Mechanisms (like try/except blocks) that catch runtime errors and allow the program to recover gracefully instead of halting.

🎨 Visual Metaphor (Image Reference): Safety Net / Circuit Breaker
Refer to the safety net image. When a tightrope walker falls (an API rate limit is hit), the safety net catches them so the show can go on.

8. File Handling

~10 min

Goal: Explain how to persistently save and read data using the local filesystem and Context Managers.

Definition: Opening text or JSON files using with open(), which ensures the file stream is safely closed when operations finish.

🎨 Visual Metaphor (Image Reference): A Library Archive
Context managers are like a strict librarian. You request a book, you read or write in it, and the librarian guarantees it goes safely back on the shelf (closed), even if a fire alarm goes off (an error occurs).

9. Concurrency (Multithreading & Multiprocessing)

~10 min

Goal: Explain how to do multiple things at once to speed up slow operations.

Definition: Multithreading uses shared memory to handle multiple I/O-bound tasks concurrently. Multiprocessing spins up separate CPU processes for heavy math tasks.

🎨 Visual Metaphor (Image Reference): The Office Workspaces
Multithreading: Multiple workers at one shared desk sharing paperwork (memory). Perfect while waiting for mail/deliveries (I/O & API calls).
Multiprocessing: Completely separate private office suites with dedicated workers. No shared paperwork, allowing 100% independent heavy number crunching.

10. Calling API

~10 min

Goal: Demonstrate the core loop of every GenAI application: gathering input, making the API call, and parsing the response.

Definition: Loading hidden credentials securely from a .env file, then utilizing an SDK (like OpenAI's) to communicate with a remote server over the internet.

🎨 Visual Metaphor (Image Reference): Restaurant Order Waiter
You (the client) give your prompt to the Waiter (the API request). The Waiter takes it to the Kitchen (the LLM server), waits for the food to be prepared, and brings the parsed response back to your table.
Context Setting for Next Session:
Say a one-line note at the end of this section like: "Next session, we'll go under the hood — this same idea, but with raw HTTP requests to any API, not just via a ready-made SDK."

11. Summary & Practice Activity

~5 min

Goal: Recap everything and introduce the capstone practice activity.

📝 Homework to assign: "Personal Task Prioritizer"
Have students build a single cohesive script that utilizes everything they learned:
- Create a Task class with priority and deadlines.
- Raise a custom InvalidPriorityError for bad data.
- Save all tasks to a tasks.json file using File Handling.
- Optionally use lambdas to sort urgent tasks, or integrate the API demo to ask the LLM what to tackle first!

Preview next session: Advanced Python & APIs (HTTP requests, parsing nested JSON, rate limit handling, and API integration).
