# Presentation Content Rules

When adding, removing, or modifying sections in the `index.html` presentation, you MUST ensure that the overview summaries stay perfectly synchronized with the actual content sections.

Specifically:
1. **The Navigation Pills (Navbar)**: Ensure that all top-level pills map correctly to the active sections.
2. **The "Why These Topics Matter" list (Introduction section)**: Must list all taught topics in order.
3. **The "So far we learnt" list (Summary section)**: Must summarize all taught topics in order.

Never add new content to the presentation without updating these overview sections to match.
